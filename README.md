# astrbot_plugin_hajimi
astrbot_plugin_hajimi 是一个专为 AstrBot 设计的 Gemini 真实浏览器拟人操作与多模态创作插件。通过 Playwright 异步自动化引擎与深度防反自动化指纹伪装（Stealth Evade）、双域根凭证持久化技术，本插件能够在无头或有头 Chromium 浏览器中直接模拟真人操作 Google Gemini 网页端，同时支持 网页端深度文本对话问答、图片创作/改图（换脸/换头、素描、二次元、赛博朋克等）、GIF 动图、Veo 视频生成、Lyria 音乐合成、自动 LRU 缓存清理、用量限额查询 等全部高级网页端功能！
